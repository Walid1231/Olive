## Olive 1.4.1 · Faster updates

- **Much smaller download**: Olive.apk is now built only for 64-bit phones (almost every phone since 2017), about 45 MB smaller. Old 32-bit phones get **Olive-32bit.apk** automatically.
- **Faster in-app updates**: the update downloads over 4 connections at once, and picks up where it stopped if the internet drops.
